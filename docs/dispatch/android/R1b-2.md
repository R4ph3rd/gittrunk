- Wave: 2 (parallel with UI-A, C2). **Stretch**: if it cannot pass the gate, it is dropped from this round and the capability flags stay `false` (the UI hides the features), which is an acceptable v1.
- Agent: `rust-git-agent`, model **sonnet**
- Branch/worktree: `feat/android-r1b2-shim-advanced`
- Read first: `docs/dispatch/android/COMMON.md`, `docs/PLAN.md` §11, `docs/ANDROID_PLAN.md` §1.4 (R1b-2 bullet), §5; the merged shim in `src-tauri/src/git/cli/embedded/` (R1b-1), `src-tauri/src/platform.rs`, R1a's pull dialect in `docs/dispatch/android/R1a.md`.

## Goal

Replace the three stubs in the embedded shim with libgit2 implementations: non-interactive rebase (used by the rebase command and by pull with the rebase strategy), `worktree list --porcelain | add | remove`, and best-effort `log --follow -- <path>`; then flip the matching capability constants so the UI exposes them on Android. Interactive rebase stays unsupported.

## Owned files

Modify: `src-tauri/src/git/cli/embedded/{rebase.rs, worktree.rs, log.rs}` (keep each file's `pub fn run(...)` entry signature from R1b-1), `src-tauri/src/platform.rs` (only the three constants below), and annotation-only edits (removing `#[cfg(not(embedded_git))]` from tests your handlers now satisfy) in `src-tauri/src/git/{history,advanced}/tests.rs` and `src-tauri/src/git/remote/tests.rs`. You may add `src-tauri/src/git/cli/embedded/tests_advanced.rs` (declare it from inside one of your files with `#[cfg(test)] #[path = ...] mod tests_advanced;` so you do not edit `embedded/mod.rs`).

Must NOT touch: `embedded/mod.rs` and the other R1b-1 handlers (report shim bugs instead, or fix them only if a one-line fix blocks you, and say so), `ipc/**`, `Cargo.toml`, frontend.

## Contract

- `rebase <upstream>` / `rebase --onto <newbase> <upstream> [<branch>]` / `rebase --continue | --abort | --skip` as used by `git/history/rebase.rs`, `git/history/sequencer.rs` and R1a's pull (`["rebase", "<oid>"]`): `git2::Rebase` with in-memory = false so `repo.state()` reports a rebase; conflicts stop with exit 1 and git-like `CONFLICT` lines; `--continue` commits the resolved step (author preserved, committer from config) and proceeds; `--abort` restores; `--skip` skips. Fast-forward and up-to-date cases print what git prints. `rebase -i` (and any `GIT_SEQUENCE_EDITOR` flow) stays unsupported.
- `worktree list --porcelain` output byte-compatible with git's porcelain format for what `git/advanced/worktree.rs` parses; `worktree add [-b <branch>] <path> [<commit-ish>]`, `worktree remove [--force] <path>` via libgit2's worktree API.
- `log --follow` with the exact flags/format `git/advanced/history.rs` passes: revwalk with path filter and rename detection (`DiffFindOptions`), output in the same format the parser expects. Best effort: document known divergences.
- `platform.rs`: set `SUPPORTS_REBASE`, `SUPPORTS_WORKTREES`, `SUPPORTS_FILE_HISTORY` to `true` for each feature whose existing tests pass under `--features embedded-git` (you may flip only a subset). Update R0's `platform_info` tests if they assert these values (that test is in `commands/app.rs`: adjust only the expected values).
