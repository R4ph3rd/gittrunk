## Step 3: composite action `.github/actions/build-android/action.yml` (C1b)

Contract (C2's `release.yml` calls it; keep names exact):

- Inputs: `abis` (default `aarch64,x86_64`; allowed `aarch64`, `armv7`, `x86_64`), `sign` (`dev` | `release`, required), `keystore-base64`, `keystore-password`, `key-alias`, `key-password` (release only), `lto` (`""` = profile default, `thin` for push/PR).
- Outputs: `apk-path` (absolute path of the single renamed APK in `out/`), `version`.
- Result: exactly one file `out/gittrunk_<version>_android-universal.apk` when `abis` is `aarch64,armv7,x86_64`, else `out/gittrunk_<version>_android-<abis with commas replaced by ->.apk`.

Steps (all `shell: bash`), following ANDROID_PLAN §3.2 with these requirements:

1. Node 22 + Corepack + pnpm store cache + `pnpm install --frozen-lockfile`, copied from `build-windows.yml` (same action versions, same `COREPACK_ENABLE_DOWNLOAD_PROMPT: "0"`).
2. `actions/setup-java@v5` temurin 17, `cache: gradle`, `cache-dependency-path` pointing at the Gradle files under `src-tauri/gen/android`.
3. `dtolnay/rust-toolchain@stable` with `targets` mapped from `abis`; `Swatinem/rust-cache@v2` with `workspaces: src-tauri` and a key including the abis and `lto`.
4. NDK env from `ANDROID_NDK_LATEST_HOME` (`NDK_HOME`, `ANDROID_NDK_HOME`, `ANDROID_NDK_ROOT`, toolchain `bin` on `GITHUB_PATH`); fail with `::error::` if the variable is empty. Log `ls "$ANDROID_HOME/platforms" "$ANDROID_HOME/build-tools"`.
5. Signing: `release` requires all four secrets (fail listing which input is empty, never print values), decodes to `$RUNNER_TEMP/release.jks`; `dev` generates a throwaway keystore with a random password (`openssl rand -hex 16`, `::add-mask::` before any use) and emits the `::notice::` from ANDROID_PLAN §3.2. Both write `src-tauri/gen/android/keystore.properties` and delete it and the keystore in an `if: always()`-equivalent cleanup (composite actions have no `post`; do cleanup at the end of the build step with `trap`).
6. Build: log `pnpm tauri android build --help | head -60`, then `pnpm tauri android build --apk --ci` with one `--target` per ABI (confirm syntax from the help output on the first run). `lto: thin` sets `CARGO_PROFILE_RELEASE_LTO=thin` and `CARGO_PROFILE_RELEASE_CODEGEN_UNITS=16`.
7. Verify: find the release APK (not `*-unsigned.apk`; exactly one), `apksigner verify --print-certs` and `aapt2 dump badging` from the newest build-tools, assert package `dev.gittrunk.client` and `sdkVersion:'24'`, list the native libs (`unzip -l | grep libgittrunk_lib.so`) and assert one per requested ABI; rename into `out/`.

## Step 4: workflows

- `.github/workflows/build-android.yml`: ANDROID_PLAN §3.3 with: triggers identical to `build-windows.yml` (+ `workflow_dispatch` input `abis`), `concurrency: build-android-${{ github.ref }}` with cancel-in-progress, `permissions: contents: read`, job `android` **named `Android APK`** (required-check context used by C2), `timeout-minutes: 75`, `sign: dev`, `lto: thin`, artifact `gittrunk-android-${{ github.sha }}` (14 days). Job `smoke` named `Android emulator smoke`, `needs: android`, `continue-on-error: true`, `timeout-minutes: 30`: download the artifact, enable KVM with the udev rule (`KERNEL=="kvm", GROUP="kvm", MODE="0666", OPTIONS+="static_node=kvm"`), `reactivecircus/android-emulator-runner@v2` (api-level 34, arch x86_64, target google_apis, `disable-animations: true`) running `bash scripts/android/smoke.sh`, then upload `smoke/` (logcat + screenshot) with `if: always()`.
- `scripts/android/smoke.sh` (bash, `set -euo pipefail`): install the APK, start `dev.gittrunk.client/.MainActivity`, wait up to 30s for `pidof`, sleep 10, `adb exec-out screencap -p > smoke/screen.png`, `adb logcat -d > smoke/logcat.txt`, fail if the process died or logcat contains `FATAL EXCEPTION`, `panicked at`, or `rustls-platform-verifier`.
