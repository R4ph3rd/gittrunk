### CSS (`src/index.css`)

Use the block form so the comma-separated media list parses reliably:

```css
/* Keep in sync with src/app/layout/queries.ts (asserted by layout.test.tsx). */
@custom-variant compact {
  @media (max-width: 767.98px), (max-height: 479.98px) and (max-width: 1023.98px) {
    @slot;
  }
}
@custom-variant coarse {
  @media (pointer: coarse) {
    @slot;
  }
}
@custom-variant short {
  @media (max-height: 479.98px) {
    @slot;
  }
}
```

In `@layer base`, add compact-only rules: `html { overscroll-behavior: none; touch-action: manipulation; }` inside the compact media query, and `@media (hover: none)` nothing else. Do not change any existing rule.

### `useLayout` / `LayoutProvider`

```ts
// src/app/layout/useLayout.ts
export type LayoutMode = "compact" | "regular";
export interface Layout {
  mode: LayoutMode;
  isCompact: boolean;
  isShort: boolean;
  isCoarse: boolean;
}
export const REGULAR_LAYOUT: Layout; // { mode: "regular", isCompact: false, isShort: false, isCoarse: false }
export function useLayout(): Layout;
// useSyncExternalStore over window.matchMedia(COMPACT/SHORT/COARSE), subscribing to "change".
// No window.matchMedia (jsdom default) => REGULAR_LAYOUT. A LayoutProvider `force` overrides
// individual fields; `mode` always equals isCompact ? "compact" : "regular".

// src/app/layout/LayoutProvider.tsx
export function LayoutProvider(props: {
  force?: Partial<Layout>;
  children: ReactNode;
}): JSX.Element;
```

No provider is required at the app root (the hook works without one); the provider exists for tests and the `/design` device frame.

### Back-button stack

```ts
// src/app/layout/back.ts
export type BackHandler = () => boolean; // return true when the press was handled
export function pushBackHandler(handler: BackHandler): () => void; // LIFO; returns unregister
export function dispatchBack(): boolean; // top-down until a handler returns true
export function installBackButton(): () => void;
// Pushes a sentinel history entry; on `popstate` calls dispatchBack() and, if handled,
// re-pushes the sentinel. If nothing handled it, the sentinel is not re-pushed, so the next
// system back leaves the page (Android then closes the activity). Idempotent; returns cleanup.
export function resetBackStackForTests(): void;

// src/app/layout/useBackHandler.ts
export function useBackHandler(handler: BackHandler, enabled?: boolean): void;
// Registers while mounted and enabled (default true); always calls the latest handler.
```

Overlays (Sheets, dialogs) register when they open, so they sit above the shell's base handler, which A registers once. That gives the priority order of MOBILE_DESIGN §4.

### Test helper (`src/test/viewport.ts`)

```ts
export function setViewport(
  width: number,
  height: number,
  opts?: { pointer?: "coarse" | "fine" },
): void;
// Installs a window.matchMedia mock evaluating (max-width), (min-width), (max-height), (min-height),
// (pointer: coarse|fine), (hover: none|hover), `and`, and comma lists against the given size;
// unknown features (e.g. prefers-color-scheme) evaluate to false. Sets innerWidth/innerHeight,
// fires "change" on live MediaQueryLists whose result flipped, and dispatches "resize".
// Default pointer: "coarse" when width < 768, else "fine".
export function resetViewport(): void; // restores the original window.matchMedia (undefined in jsdom) and size
```

`src/test/setup.ts` calls `resetViewport()` and `resetBackStackForTests()` in a global `afterEach`.

4. `layout.test.tsx`: (a) the three query strings appear verbatim in `src/index.css` (read the file with `node:fs`); (b) no matchMedia => regular; (c) `setViewport(390, 844)` => compact + coarse, not short; (d) `setViewport(844, 390)` => compact + short; (e) `setViewport(1400, 900)` => regular, fine; (f) `setViewport(800, 1280)` => regular (tablet); (g) resizing live re-renders a consumer; (h) `LayoutProvider force={{ isCompact: true }}` => mode "compact"; (i) back stack LIFO, unregister, `useBackHandler` enabled flag, `installBackButton` re-pushes the sentinel only when handled (simulate `popstate`).
5. Commits: `feat(mobile): add compact/coarse/short variants and mobile tokens`, `feat(mobile): add layout detection, back-button stack and viewport test helper`.
