## Contract to implement (others depend on these exact shapes)

### Cargo and cfg

`src-tauri/build.rs`:

```rust
fn main() {
    println!("cargo::rustc-check-cfg=cfg(embedded_git)");
    let android = std::env::var("CARGO_CFG_TARGET_OS").is_ok_and(|v| v == "android");
    if android || std::env::var_os("CARGO_FEATURE_EMBEDDED_GIT").is_some() {
        println!("cargo::rustc-cfg=embedded_git");
    }
    tauri_build::build()
}
```

`src-tauri/Cargo.toml`:

```toml
[features]
default = []
# Host-testable stand-in for the Android backend: libgit2 for all git work,
# file-backed secret store. Never enabled in desktop releases.
embedded-git = []

[dependencies]
# ... existing, minus keyring; git2 line unchanged (no https on desktop) ...
webpki-roots = "1"        # all targets, so the Android TLS path is host-testable under embedded-git

[target.'cfg(not(target_os = "android"))'.dependencies]
keyring = { version = "3", features = ["apple-native", "windows-native", "sync-secret-service", "crypto-rust"] }

[target.'cfg(target_os = "android")'.dependencies]
# Cargo unifies features per target: only Android gets TLS in libgit2.
git2 = { version = "0.21", default-features = false, features = ["vendored-libgit2", "https", "vendored-openssl"] }
```

Update the comment above the main `git2` line to mention the Android table. `keyring` code keeps compiling on the host (it is still a host dependency); R2 gates its use.

### `src-tauri/src/platform.rs`

```rust
//! Compile-time platform facts. `EMBEDDED` = no git CLI; libgit2 does everything.
pub const EMBEDDED: bool = cfg!(embedded_git);
pub const MOBILE: bool = cfg!(mobile);
// Capability switches. R1b-2 flips these to `true` when its shim handlers land.
pub const SUPPORTS_REBASE: bool = !EMBEDDED;        // non-interactive rebase, pull --rebase
pub const SUPPORTS_WORKTREES: bool = !EMBEDDED;
pub const SUPPORTS_FILE_HISTORY: bool = !EMBEDDED;  // `log --follow`
```

(`cfg(mobile)` is emitted by `tauri_build`; `lib.rs` already uses it.)

### IPC types (`ipc/types.rs`, `wire!` macro, app section)

```rust
pub struct PlatformInfo {
    pub os: String,                        // std::env::consts::OS: "android" | "windows" | "macos" | "linux"
    pub mobile: bool,                      // platform::MOBILE
    pub has_git_cli: bool,                 // !EMBEDDED
    pub can_pick_folder: bool,             // !MOBILE (SAF content URIs are not repo paths)
    pub supports_ssh: bool,                // !EMBEDDED
    pub supports_external_editor: bool,    // !MOBILE
    pub supports_rebase: bool,             // platform::SUPPORTS_REBASE
    pub supports_interactive_rebase: bool, // !EMBEDDED
    pub supports_worktrees: bool,          // platform::SUPPORTS_WORKTREES
    pub supports_submodules: bool,         // !EMBEDDED (update/init shell out)
    pub supports_file_history: bool,       // platform::SUPPORTS_FILE_HISTORY
    pub supports_hooks: bool,              // !EMBEDDED (hooks and commit signing)
    pub secret_store: String,              // "file" when EMBEDDED, else "keychain"
    pub default_repos_dir: Option<String>, // Some(<app_data_dir>/repos) when MOBILE || EMBEDDED, created if missing
}

pub struct GitIdentity {
    pub name: Option<String>,
    pub email: Option<String>,
}
```

`ErrorKind::Unsupported` is added right after `NotImplemented` (serialized `"unsupported"`). Add a helper `AppError::unsupported(what: &str) -> AppError` with message `"<what> is not supported on this platform"`.

### Commands (register in `ipc/mod.rs` after `app_info`, in this order)

```rust
// commands/app.rs
#[tauri::command] #[specta::specta]
pub async fn platform_info(app: tauri::AppHandle) -> AppResult<PlatformInfo>;
// Pure core, unit-tested: pub fn platform_info_for(data_dir: Option<&Path>) -> PlatformInfo

// commands/app.rs: lets the Android back handler close the app ("press back again to exit").
#[tauri::command] #[specta::specta]
pub async fn app_exit(app: tauri::AppHandle) -> AppResult<()>;   // app.exit(0)

// commands/identity.rs
#[tauri::command] #[specta::specta]
pub async fn git_identity_get() -> AppResult<GitIdentity>;          // user.name/user.email from the default config chain
#[tauri::command] #[specta::specta]
pub async fn git_identity_set(name: String, email: String) -> AppResult<GitIdentity>; // writes the GLOBAL config level

// commands/repo.rs
#[tauri::command] #[specta::specta]
pub async fn repo_delete(app: tauri::AppHandle, state: tauri::State<'_, GitState>, path: String) -> AppResult<()>;
```

- `app_info`: when `EMBEDDED`, `git_version = Some(format!("libgit2 {}.{}.{} (embedded)", ..))` from `git2::Version::get().libgit2_version()`; unchanged otherwise.
- Identity: trim both; `InvalidInput` if empty or containing `\n`/`\r`/`<`/`>`. Write to the global config file: `git2::Config::find_global()`, and if none exists yet, create `.gitconfig` in the global search directory (on Android R2 points that at the app data dir; on desktop it is `$HOME`). Put the logic in testable functions that take a config-file `&Path`; unit tests must only use temp files and never read or write the real `~/.gitconfig`.
- `repo_delete`: `Unsupported` when there is no default repos dir (desktop). Canonicalize both paths; refuse (`InvalidInput`) unless `path` is strictly inside the default repos dir. Close any open repository at that path (add `GitState` helper), remove it from recent repos (add `RecentStore` helper), then `std::fs::remove_dir_all`. Unit-test the path guard (`..`, symlink escape, equal to the root, outside) on temp dirs.
