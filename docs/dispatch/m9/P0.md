## Avatar

```tsx
export interface AvatarProps {
  /** Display name: initials and the accessible title. */
  name: string;
  /** Image URL (a data: URL from the backend); null/undefined or a load error shows initials. */
  src?: string | null;
  /** Pixel size, default 20. */
  size?: number;
  /** CSS color for the fallback disc and the optional ring, default "var(--accent)". Pass laneVar(n). */
  color?: string;
  /** 2px ring in `color` separated by --avatar-ring. */
  ring?: boolean;
  className?: string;
}
export function Avatar(props: AvatarProps): JSX.Element;
/** Up to two uppercase letters: first letters of the first two words of `name`, else the first two characters of the email local part, else "?". */
export function initials(name: string): string;
```

Rendering: a round `span` with `title={name}` and `aria-hidden` (callers show the name as text); the image is `<img alt="" draggable={false}>` with `object-cover`; fallback text uses `--lane-fg` on `color`, font size ~ `size * 0.42`, semibold. Tests (`avatar.test.tsx`): initials rules (`"Ada Lovelace"` -> `AL`, `"r4ph3rd"` -> `R4`, `"dev@example.com"` -> `DE`, `""` -> `?`), image shown when `src` is set, fallback after an `error` event, `size` applied.

## Contrast test

`src/design/contrast.test.ts` reads `tokens.css` (`fs`), extracts hex values of the dark block (`:root, [data-theme="dark"]`) and the light block, resolves `var(--x)` references, computes WCAG contrast and asserts, for both themes:

- ≥ 4.5: `--fg`, `--fg-muted` on `--bg`, `--bg-subtle`, `--surface`, `--surface-raised`, `--surface-hover`, `--toolbar-bg`, `--tabbar-bg`; `--fg-subtle` on `--bg`, `--bg-subtle`, `--surface`, `--surface-raised`, `--surface-hover`, `--toolbar-bg`; `--accent`, `--danger`, `--success`, `--warning` on `--surface` and `--bg`; `--accent-fg` on `--accent`; `--danger-fg` on `--danger`; `--lane-fg` on every `--lane-N`.
- ≥ 3: every `--lane-N` on `--surface`; `--accent` on `--tabbar-bg` (indicator).

The values above were pre-checked; if a pair fails, adjust that value by the smallest step and record it in DESIGN.md.
